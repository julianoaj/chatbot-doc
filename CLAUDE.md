# Chatrapido API Documentation

Documentation project for Chatrapido API using Scalar.

## Project Structure
- `docs-openapi.json`: OpenAPI specification for the API.
- `scalar.config.json`: Scalar configuration for the documentation site.

## Development Commands
- `npx @scalar/cli project preview`: Preview documentation locally.
- `npx @scalar/cli project check-config`: Validate configuration.

## Coding Standards
- Maintain valid OpenAPI 3.1.1 specification.
- Use clear and descriptive names for endpoints and schemas.
- Ensure documentation matches API implementation.
